# MungPhai Trips & Tours — Premium Website Design System

## Design Goal

Create a premium luxury travel website inspired by high-end travel brands.

The UI should feel like a combination of
- Apple
- Aman Resorts
- Akina Hotel (reference)
- Modern Glassmorphism
- Luxury Travel Agency

NOT a template website.

Everything should feel expensive, smooth, minimal and elegant.

---

# Design Style

- Luxury
- Premium
- Elegant
- Soft Glassmorphism
- Rounded Corners
- Cinematic Photography
- Golden Accent
- Minimal UI
- Large White Spaces
- Smooth Animations

The website should immediately communicate trust and luxury.

---

# Color Palette

## Primary
Luxury Gold: `#C8A24E`
Dark Gold: `#A87E2A`
Champagne Gold: `#E7D5A0`

## Background
Deep Charcoal: `#0D0D0D`
Rich Black: `#090909`
Secondary Background: `#111111`
Glass Background: `rgba(255,255,255,0.08)`
Glass Border: `rgba(255,255,255,0.18)`

## Text
Primary: `#FFFFFF`
Secondary: `#D9D9D9`
Muted: `#A1A1A1`
Accent: `#C8A24E`

---

# Typography

## Heading Font
Playfair Display (600, 700)
- Large Hero: 72px
- Section Titles: 54px
- Card Titles: 28px

## Body Font
Manrope (400, 500, 600)
- Paragraph: 18px
- Buttons: 16px
- Navigation: 16px

---

# Border Radius
- Cards: 32px
- Buttons: 999px
- Image Cards: 28px
- Sections: 40px
- Glass Panels: 30px

---

# Shadows
- Soft Premium Shadow: `0 30px 80px rgba(0,0,0,.35)`
- Glass Shadow: `0 20px 60px rgba(0,0,0,.25)`
- Hover Shadow: `0 40px 90px rgba(0,0,0,.45)`

---

# Glassmorphism
- `backdrop-filter: blur(24px)`
- `background: rgba(255,255,255,.08)`
- `border: 1px solid rgba(255,255,255,.18)`

Never use strong opacity. Everything should feel soft.

---

# Images
Only use Ultra HD Photography. No stock-looking images. Use cinematic color grading with warm highlights, soft shadows, golden hour, fog, mountains, road trips, luxury cars, happy travelers, drone shots, tea gardens, waterfalls, sunrise. Large rounded corners.

---

# Hero Section
Full Screen background with full-width cinematic video/image. Floating Glass Card centered hero glass panel with Luxury Heading, Subheading, Book Now Button, Explore Tours Button, Scroll Indicator, Floating navigation inside the glass card.

---

# Navbar
Transparent, Blurred, Floating, Rounded. Height 72px.
Contains Logo, Home, Packages, Fleet, Gallery, Transfers, Reviews, Contact, Book Now Button.
When scrolling, glass becomes slightly darker.

---

# Buttons
- Primary: Luxury Gold, Rounded Pill. Hover Glow, Scale 1.05, Transition 300ms.
- Secondary: Glass Button, Blur, White Border.

---

# Section Style
Every section should alternate Image Left / Content Right, Image Right / Content Left.
Never stack plain text. Always use Glass Cards, Rounded Images, Floating layouts, Luxury spacing (160px section spacing).

---

# Cards
- Package Cards: Rounded 32px, Glass, Hover Lift, Destination Image, Price, Duration, CTA.
- Fleet Cards: Vehicle Image, Capacity, Type, Book Now.
- Gallery Cards: Rounded Masonry Layout, Hover Zoom, Light Overlay.

---

# Gallery
Pinterest Style, Rounded, Large images, No square grid, Hover Zoom, Glass overlay, Instagram icon.

---

# Animations
Framer Motion style: Fade Up, Slide Left, Slide Right, Parallax, Scale, Blur Reveal, Image Zoom, Stagger Animation, Smooth Scroll.

---

# Icons
Lucide Icons, Minimal 2px stroke, Gold Accent.

---

# Spacing
- Sections: 160px
- Cards: 40px
- Padding: 32px
- Container: 1440px

---

# Micro Interactions
Buttons lift, Cards float, Images zoom, Navbar blur, Cursor effects, Smooth hover, Luxury transitions.

---

# Footer
Dark Black, Glass Top Border, Logo, Quick Links, Packages, Social Links (Instagram, Google Reviews, WhatsApp, Call Now), Newsletter, Google Map, Copyright.

---

# SEO
Semantic HTML, One H1 per page, Structured H2 hierarchy, Optimized images, Lazy loading, Schema.org (TravelAgency, LocalBusiness, FAQ, Breadcrumb), Open Graph, Twitter Cards, XML Sitemap, Robots.txt, Fast loading.
